# Team Task Management

A backend API for a team task management application, built with Python, FastAPI, and PostgreSQL.

## Overview

Teamwork often involves information scattered across messages, notes, and spreadsheets, making it difficult to track responsibilities and monitor progress. This project aims to centralize that information by providing an API for user authentication, task management, and task status tracking.

This is a learning project developed for practice and exploration. It is not yet a production-ready application.

## Tech Stack

| Purpose                      | Technology                                       |
| ---------------------------- | ------------------------------------------------ |
| Programming language         | Python                                           |
| Web framework                | FastAPI (built on Starlette)                     |
| ASGI server                  | Uvicorn                                          |
| ORM                          | SQLModel, SQLAlchemy 2.0                         |
| Database                     | PostgreSQL (`psycopg2-binary` driver)            |
| Database migrations          | Alembic                                          |
| Validation and configuration | Pydantic v2, pydantic-settings, python-dotenv    |
| Authentication and security  | PyJWT, argon2-cffi, pwdlib                       |
| Error monitoring             | sentry-sdk                                       |
| Other libraries              | Jinja2, python-multipart, email-validator, httpx |

## Getting Started

### Prerequisites

- Python 3
- A running PostgreSQL instance

### Installation

1. **Install the dependencies**

   ```bash
   pip install -r requirements.txt
   ```

2. **Configure environment variables**

   Create a `.env` file containing your database connection details and secret key. Check the configuration code under `src/` for the exact environment variable names.

3. **Apply database migrations**

   ```bash
   alembic upgrade head
   ```

4. **Start the development server**

   ```bash
   uvicorn src.main:app --reload
   ```

   Adjust the module path if your application entry point is located elsewhere under `src/`.

Once the server is running, open `/docs` to access the interactive API documentation generated by FastAPI.

## What I Learned

- **Database migrations with Alembic:** Keeping schema changes version-controlled makes database updates easier to track and manage. Each model change still requires creating and reviewing the corresponding migration.
- **Working with SQLModel:** Sharing models between database tables and API schemas can reduce repetitive code. For more complex models, separating input and output schemas helps prevent sensitive fields, such as passwords, from being exposed.
- **Authentication and password security:** Passwords should be hashed with a dedicated password-hashing algorithm, such as Argon2, and authentication can be handled with JWTs rather than a custom mechanism.
- **Input validation and configuration:** Pydantic validates incoming API data, while environment variables help keep configuration values and secrets out of the source code.
- **Error monitoring with Sentry:** Error monitoring helps identify issues that occur while the application is running.
